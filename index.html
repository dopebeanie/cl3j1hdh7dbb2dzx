Z-Aura

Документы рабочего Windows-приложения · редакция 25.11.2026

Z-Aura — локальный интерфейс для управления профилями и ресурсами zapret/Flowseal, запуска собственного движка, настройки службы Windows и проверки доступности выбранных адресов.

Приложение не является VPN, не добавляет шифрование и не гарантирует анонимность или доступность сайтов. Использовать его следует только там, где это разрешено законом и правилами вашей сети.

Discord Rich Presence. Пока Z-Aura работает, приложение передаёт запущенному desktop-клиенту Discord выбранный профиль и состояние собственного движка. Discord может показывать эту информацию другим пользователям в соответствии с настройками видимости активности.

Функции Discord

Rich Presence независима от необязательного входа через Discord. Вход выполняется в браузере Discord с S256 PKCE и разрешением identify; локальная страница возвращает пользователя в запущенное окно. Сеанс сохраняется на устройстве с защитой Windows DPAPI для текущего пользователя. Серверного хранилища токенов Z-Aura, slash-команд, обработчиков взаимодействий и привязанных ролей нет.

Публикация документов не означает прохождение проверки Discord. Настройка и одобрение приложения выполняются отдельно в Developer Portal.

Статус сборки

Текущая Windows-сборка является кандидатом на выпуск. Проверки на чистой Windows, работа службы/драйвера в реальных условиях, подпись издателя и проверка условий распространения сторонних компонентов остаются отдельными требованиями. Этот сайт не содержит ссылки на скачивание непроверенной сборки.
